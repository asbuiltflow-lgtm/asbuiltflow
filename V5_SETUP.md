# AsBuiltFlow Sales Demo V5

This release is a visual and interaction polish pass for the browser-based sales demo.

## Improvements
- Role-aware, clickable workflow stepper
- Clear completed, current, available, and upcoming workflow stages
- Recommended next-action card based on role and project status
- More polished project action cards for PDFs, photos, revisions, and issues
- Stronger project summary metrics
- Improved plan legend, hover states, focus states, spacing, and mobile behavior
- Mobile photo input still supports camera capture and gallery selection

## Important limitation
This is an interactive sales demonstration using browser-local sample data. Do not use confidential or production documents until authentication, database storage, private file storage, and organization security are connected and tested.
