# AsBuiltFlow Pilot Workspace v3

V3 improves the pilot presentation while retaining the role-based browser demo introduced in V2.

## Presentation changes

- Replaced the internal Supabase warning with professional demo-environment wording.
- Added a clear sample-data notice inside the workspace.
- Redesigned Priority Projects into polished, responsive cards.
- Redesigned Issues Needing Attention into consistent issue cards.
- Added improved hover states, spacing, typography, empty states, and mobile behavior.

## Important limitation

This remains a browser-based demonstration. Do not use confidential or production customer documents until authentication, private cloud storage, database persistence, and server-enforced permissions are connected and tested.

## Run locally

```bash
npm install
npm run dev
```

Open `/app` to test the role-based workspace.
